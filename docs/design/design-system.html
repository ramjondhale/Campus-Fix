CampusFix Design System

One set of tokens and components for the reporter, maintenance, verifier and admin apps. The Flutter package campusfix_design implements these values one to one.

Apps
Flutter mobile · Flutter Web admin

Text always names the state

Status, priority and category colour never carry meaning alone. Every badge, tag and chip prints its label (G-8).

Flat first

A 1 px outline carries structure. Shadows are kept for things that float: menus, dialogs, sheets and toasts.

No slot for identity

Board, list and maintenance components accept public fields only. They have no place to put a reporter name (R5).

§2

Color

A petrol teal brand over cool-biased neutrals. Semantic sets for category, priority and status are generated at fixed lightness so every set carries the same visual weight. 200 contrast pairs were checked in both themes (text 4.5:1 or better, accents and control outlines 3:1 or better): 0 failures.

2.1

How the sets work

Every semantic set has three values per theme. Shown here with the In Progress status in the current theme.

fg and bgText and icons use fg on the set bg. Guaranteed 4.5:1 or better on that bg only.
accent marks non-text shapes: ring, signal bar, dot, node, chart fill. 3:1 or better against card and bg. Never text.

§9

Accessibility rules

Rules every component follows. Contrast values are in section 2; behaviour rules are here.

  • Text 4.5:1 or better on its surface in both themes; icons, accents and control outlines 3:1 or better (section 2.9).
  • Status, priority and category are always printed as text (G-8, G-12). Colour is never the only signal.
  • Mobile touch targets are at least 48 × 48; pointer targets at least 32 × 32.
  • Focus is a visible 2 px ring with 2 px offset on every interactive element, in both themes, and is never removed.
  • Every control has a semantic label. Icon-only buttons carry a tooltip and a label. Tiles use radio or toggle semantics.
  • BeforeAfter is a keyboard slider; the split mode is the no-drag alternative.
  • Text scales with the OS up to 200% without clipping or overlap.
  • Reduced motion removes slide, scale and shimmer animation.
  • Toasts announce politely and never hold the only copy of an error. Dialogs trap focus and restore it on close.
  • Form errors name the problem and the fix, are linked to the field, and are not colour-only.
