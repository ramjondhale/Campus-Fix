# campusfix_design_example

A minimal app that shows `WidgetGalleryScreen` from `campusfix_design`: every
component of design contract section 8 in all its variants and states, with a
light / dark toggle. It is the visual-QA surface for the design system.

```
cd packages/campusfix_design/example
flutter run -d chrome    # or an iOS simulator
```

The gallery uses `PublicComplaintView` fixtures only; no reporter identity
appears in it.
